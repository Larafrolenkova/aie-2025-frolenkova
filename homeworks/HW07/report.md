## 1. Datasets

В работе были выбраны три датасета из четырёх предложенных: dataset_01, dataset_02 и dataset_04.

### 1.1 Dataset A

- Файл: `S07-hw-dataset-01.csv`
- Размер: (1200 строк, 8 столбцов)
- Признаки: числовые
- Пропуски: отсутствуют
- "Подлости" датасета: признаки находятся в разных шкалах, присутствуют шумовые признаки

Датасет предназначен для демонстрации влияния масштабирования признаков на
distance-based методы кластеризации.

### 1.2 Dataset B

- Файл: `S07-hw-dataset-02.csv`
- Размер: (8000 строк, 3 столбца)
- Признаки: числовые
- Пропуски: отсутствуют
- "Подлости" датасета: нелинейная структура кластеров, наличие выбросов и фонового шума

Датасет хорошо иллюстрирует ограничения KMeans и преимущества плотностных методов.

### 1.3 Dataset C

- Файл: `S07-hw-dataset-04.csv`
- Размер: (10000 строк, 32 столбца)
- Признаки: числовые и категориальные
- Пропуски: присутствуют в числовых признаках
- "Подлости" датасета: высокая размерность, категориальные признаки и пропуски

Датасет требует аккуратного препроцессинга перед применением алгоритмов кластеризации.

## 2. Protocol

Для всех датасетов использовался единый и честный unsupervised-протокол.

Препроцессинг включал масштабирование числовых признаков с помощью StandardScaler.
Для dataset_04 дополнительно выполнялась обработка пропусков (SimpleImputer)
и кодирование категориальных признаков с использованием OneHotEncoder.
Препроцессинг оформлялся явно и одинаково применялся ко всем моделям данного датасета.

Подбор гиперпараметров осуществлялся путём перебора разумных диапазонов:
- для KMeans подбиралось число кластеров k в диапазоне от 2 до 20;
- для DBSCAN подбирались параметры eps и min_samples;
- для AgglomerativeClustering подбирались k и вариант linkage.

Лучшее решение выбиралось на основе совокупности метрик качества:
silhouette score (максимизация), Davies–Bouldin score (минимизация) и
Calinski–Harabasz score (максимизация).
Для DBSCAN метрики рассчитывались только по non-noise объектам, при этом доля шума
фиксировалась явно.

Для визуализации использовалась PCA(2D). PCA применялась исключительно для
визуального анализа структуры данных и не рассматривалась как метрика качества.

## 3. Models

Для каждого датасета сравнивались следующие модели:

- KMeans:
  - подбирался параметр k;
  - фиксировались random_state и n_init;
- Второй алгоритм:
  - dataset_01 и dataset_04: AgglomerativeClustering (подбор k и linkage);
  - dataset_02: DBSCAN (подбор eps и min_samples, анализ доли шума).

Опциональные методы и дополнительные параметры использовались для проверки гипотез,
но не рассматривались как основные.

## 4. Results

### 4.1 Dataset A

- Лучший метод и параметры: KMeans, k=2
- Метрики:
  - silhouette ≈ 0.522
  - Davies–Bouldin ≈ 0.685
  - Calinski–Harabasz ≈ 11787
- Коротко: данные имеют чёткую шарообразную структуру кластеров, поэтому
  KMeans и AgglomerativeClustering дали эквивалентные результаты.

### 4.2 Dataset B

- Лучший метод и параметры: DBSCAN, eps=1.0, min_samples=20
- Метрики:
  - silhouette ≈ 0.457
  - Davies–Bouldin ≈ 0.535
  - Calinski–Harabasz ≈ 72.6
- Доля шума: ~1.1%
- Коротко: DBSCAN оказался более уместным из-за нелинейной структуры кластеров
  и наличия выбросов, с которыми KMeans справлялся хуже.

### 4.3 Dataset C

- Лучший метод и параметры: KMeans, k=5
- Метрики:
  - silhouette ≈ 0.447
  - Davies–Bouldin ≈ 0.976
  - Calinski–Harabasz ≈ 5088
- Коротко: после корректного препроцессинга KMeans и AgglomerativeClustering
  показали одинаковое качество, что указывает на адекватно выделяемую структуру данных.

## 5. Analysis

### 5.1 Сравнение алгоритмов (важные наблюдения)

KMeans хорошо работает на данных с компактными и примерно сферическими кластерами,
но чувствителен к выбросам и нелинейным формам. DBSCAN выигрывает в задачах с шумом
и кластерами произвольной формы, однако чувствителен к выбору параметров плотности.
Иерархическая кластеризация показала себя устойчивой альтернативой KMeans
при корректном выборе linkage.

Ключевыми факторами качества оказались масштабирование признаков, наличие выбросов,
плотность кластеров и корректная обработка пропусков и категориальных признаков.

### 5.2 Устойчивость (обязательно для одного датасета)

Для dataset_01 была выполнена проверка устойчивости KMeans (k=2) путём 5 запусков
с разными значениями random_state. Похожесть разбиений оценивалась с помощью
Adjusted Rand Index (ARI).

Все значения ARI оказались близки к 1, что свидетельствует о высокой устойчивости
кластеризации и слабой зависимости результата от инициализации центров.

### 5.3 Интерпретация кластеров

Интерпретация кластеров проводилась на основе визуализации в пространстве PCA
и анализа относительного расположения объектов. Для dataset_01 и dataset_04
кластеры демонстрируют компактные и хорошо разделённые группы, тогда как
для dataset_02 наблюдается более сложная структура с выделением шума.

Полученные кластеры согласуются с ожидаемыми свойствами синтетических данных.

## 6. Conclusion

- Масштабирование является критически важным этапом для distance-based методов.
- KMeans эффективен для компактных кластеров, но чувствителен к выбросам.
- DBSCAN лучше справляется с шумом и нелинейными структурами.
- Иерархическая кластеризация может давать качество, сопоставимое с KMeans.
- Использование нескольких метрик даёт более надёжную оценку качества.
- PCA полезна для визуального анализа, но не заменяет количественные метрики.
- Устойчивость кластеризации следует проверять явно, даже в unsupervised-задачах.
