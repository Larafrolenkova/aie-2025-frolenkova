# S03 – eda\_cli: мини-EDA для CSV

Небольшое CLI- и API-приложение для базового анализа CSV-файлов. Используется в рамках Семинара 03 курса «Инженерия ИИ».

Проект включает:

- CLI-интерфейс (`eda-cli`) для запуска EDA из командной строки;
- HTTP API (FastAPI) для программного доступа к результатам анализа.

---

## Требования

- Python 3.11+
- [uv](https://docs.astral.sh/uv/) установлен в систему

---

## Инициализация проекта

В корне проекта (S03):

```bash
uv sync
```

Эта команда:

- создаст виртуальное окружение `.venv`;
- установит зависимости из `pyproject.toml`;
- установит сам проект `eda-cli` в окружение.

---

## Запуск CLI

### Краткий обзор данных

```bash
uv run eda-cli overview data/example.csv
```

Параметры:

- `--sep` – разделитель (по умолчанию `,`);
- `--encoding` – кодировка (по умолчанию `utf-8`).

---

### Полный EDA-отчёт

```bash
uv run eda-cli report data/example.csv --out-dir reports
```

В результате в каталоге `reports/` появятся:

- `report.md` – основной отчёт в формате Markdown;
- `summary.csv` – таблица со статистиками по колонкам;
- `missing.csv` – информация о пропущенных значениях;
- `correlation.csv` – корреляционная матрица (для числовых признаков);
- `top_categories/*.csv` – top-k категорий для строковых признаков;
- `hist_*.png` – гистограммы числовых колонок;
- `missing_matrix.png` – визуализация пропусков;
- `correlation_heatmap.png` – тепловая карта корреляций.

## Запуск API-сервиса

Для запуска HTTP API используется ASGI-сервер **uvicorn** и фреймворк FastAPI.

Команда запуска сервера:

```bash
uv run uvicorn eda_cli.api:app --reload
```

где:

- `eda_cli.api` — модуль с API-приложением;
- `app` — экземпляр FastAPI-приложения.

После запуска сервис будет доступен по адресу:

```
http://127.0.0.1:8000
```

Автоматическая документация API (Swagger UI):

```
http://127.0.0.1:8000/docs
```

## API-эндпоинты

### Health-check

```http
GET /health
```

Простейший системный эндпоинт для проверки доступности сервиса. Возвращает статус, имя сервиса и версию.

---

### Оценка качества по агрегированным признакам

```http
POST /quality
```

Описание:

- принимает агрегированные характеристики датасета (число строк, колонок, доля пропусков и т.д.);
- использует эвристическую модель качества;
- возвращает интегральную оценку качества и флаги.

Используется как **заглушка модели качества данных**.

---

### Оценка качества по CSV-файлу

```http
POST /quality-from-csv
```

Описание:

- принимает CSV-файл;
- запускает EDA-ядро (summarize\_dataset, missing\_table, compute\_quality\_flags);
- возвращает итоговую оценку качества датасета;
- связывает CLI-логику из HW03 и HTTP-сервис из HW04.

---

### Новый эндпоинт: полный набор флагов качества (HW04)

```http
POST /quality-flags-from-csv
```

Описание:

- **новый эндпоинт HW04**;
- принимает CSV-файл;
- прогоняет данные через EDA-ядро из HW03;
- возвращает полный набор флагов качества данных (эвристики);
- используется для детальной диагностики проблем датасета.

Пример запроса:

```bash
curl -X POST "http://127.0.0.1:8000/quality-flags-from-csv" \
  -F "file=@data/example.csv"
```

Эндпоинт реализован в модуле `eda_cli.api` и является дополнительным по отношению к базовым эндпоинтам качества.
